# Regras de conteúdo e rotas

- Preserve IDs de posts publicados e paths legados.
- Crie conteúdo apenas com dados verificáveis; não invente anúncios, datas, avaliações, licenças ou obras.
- Mídia exige fonte, autorização/licença e crédito antes da publicação.
- Conteúdo público deve ter schemas válidos e referências resolvíveis.
- Rascunhos ficam fora de páginas estáticas públicas, listagens, busca, RSS e relações públicas.
- Use `basePath()` para links internos sob GitHub Pages.
- Registre decisão arquitetural em ADR e evidências em relatório da fase.
- Rode `npm test`, `npm run build` e `npm run test:e2e` quando modificar código de conteúdo/rotas.
