# Anime & Manga Blog — Pacote SDD

Plano de transformação incremental para projeto Astro estático existente. **Não representa uma auditoria do repositório real.**

## Execução

Este pacote é mantido como fonte de referência histórica. O roteiro foi executado e os resultados reais estão nos relatórios em `../reports/` e `../audits/`.

Para consulta, os prompts estão em `prompts/PROMPT-00.md` até `PROMPT-10.md`; as especificações distribuídas originalmente com o pacote estão em `reference/`.

## Entregáveis

- `reference/VISION.md`: visão e escopo originais.
- `reference/REQUIREMENTS.md`: requisitos iniciais.
- `reference/ARCHITECTURE.md`: arquitetura e dados previstos.
- `prompts/PROMPT-00.md` até `PROMPT-10.md`: implementação e auditoria.

Os prompts são o pacote fonte original; decisões atuais e estado verificável estão documentados na raiz de `docs/`.
