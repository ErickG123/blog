# Visão do produto

Transformar o blog Astro de programação em um blog brasileiro completo de anime e mangá, sem substituir desnecessariamente sua fundação estática. Notícias, reviews, guias, recomendações, temporadas e páginas de obras formam uma experiência editorial coesa, rápida e acessível.

## Público

Leitores de anime e mangá em português, interessados em descobertas, análises e atualizações editoriais.

## MVP

Nova identidade; home; listagens por tipo; artigos; busca/tags; catálogo e páginas de obras; temporadas; SEO/RSS; Giscus; GitHub Pages.

## Fora de escopo inicial

Painel administrativo, login, banco de dados, comentários próprios, integrações automáticas de terceiros e serviços backend.

## Princípios

Static-first, dados editados via Git, tipos seguros, URLs estáveis, imagens com autorização, dados verificáveis, acessibilidade, responsividade, sem visual genérico de revista ou emojis.
