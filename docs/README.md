# Documentação do projeto

- `specifications/`: visão, requisitos e critérios de aceite atuais.
- `architecture/`: arquitetura do código e ADRs vigentes.
- `audits/`: evidências das auditorias, incluindo baseline e fases 11–12.1.
- `reports/`: execução, resultados de testes, pendências e prontidão de release por fase, incluindo comparação visual antes/depois da Fase 12.1.
- `content-editorial-guide.md`: orientação para criar conteúdo verificado.
- `content-proposal-phase-11.md`: pauta proposta, separada de conteúdo publicado.
- `sdd-source/`: pacote original de prompts e especificações, preservado dentro de `docs/` para consulta.

Os relatórios de fase descrevem o estado observado. Use a auditoria mais recente e o roadmap para distinguir implementação de conteúdo editorial ainda pendente.
